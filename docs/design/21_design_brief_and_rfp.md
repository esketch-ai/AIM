# AIM — 디자인 전문팀 의뢰서 및 플랫폼 UI/UX 디자인 브리프 (Design Brief & RFP)

> **문서 버전**: v1.0  
> **수신**: 전문 UI/UX 디자인 에이전시 / 프로덕트 디자인팀  
> **발신**: AIM (AI Platform Initiative) 총괄 기획 & 엔지니어링 팀  
> **기준 테마**: Calm Ergonomic Dark System (2026 APCA 인체공학 테마)  
> **목적**: 동네 자영업 사장님을 위한 1-Click 자율 운영 & 마케팅 인프라 플랫폼의 프로덕션 수준 모바일 앱/웹 및 어드민 UI/UX 디자인 의뢰

## 1. 프로젝트 개요 & 플랫폼의 본질 (Project Overview & Identity)

### 1.1 서비스 한 줄 정의 (Killer One-Liner)
> **"매출 고민 끝 — 실시간 인프라(날씨·상권·기념일)를 감지해 오늘 할 일 딱 1개를 추천하고, 1-Click으로 콘텐츠 생성부터 네이버·인스타 자동 배포 및 매출 검증까지 끝내는 사장님 전용 자율 운영 비서"**

### 1.2 해결하려는 본질적 문제 (The Problem)
대한민국 골목상권 자영업 사장님(요식업, 뷰티, 카페, 소매점 등)은 매출이 저조할 때 극심한 고통과 혼란을 겪습니다:
1. **무엇을 해야 할지 모름**: 가장 효과적인 것은 전문 컨설팅이지만 수백~수천만 원의 비용이 발생해 엄두를 내지 못하고, 주변 지인에게 조언을 구하다 시간을 낭비합니다.
2. **어떻게 해야 할지 모름**: 유튜버, 블로거, 방송에 매장을 알리고 싶어도 누구에게 어떻게 연락해야 할지 모르고(사기 우려), SNS 프로모션을 하려 해도 글을 쓰고 디자인할 시간과 역량이 없습니다.
3. **효과를 알 수 없음**: 기존 마케팅 대행사는 노출수(Impression), 클릭수(CTR) 등 소상공인이 이해할 수 없는 지표만 나열하며 실제 매장 매출과 연결해 주지 못합니다.

### 1.3 AIM의 해결 방식: 3단계 자율 플라이휠 (The 3-Step Flywheel)
AIM은 사장님이 공부하거나 고민할 필요가 없도록 **도시 인프라 데이터와 AI 업무 자동화**를 결합했습니다:
```
[1단계: 감지 (Sense)]
날씨, 지역 행사, 동네 상권, 요일/시간, 기념일 등 인프라 신호 24시간 실시간 감지
       ↓
[2단계: 진단 및 추천 (Prescribe)]
복잡한 선택지 배제! "사장님, 오늘 비가 오니 파전 세트로 인스타/네이버에 소식을 올리세요" (딱 1개 맞춤 조언)
       ↓
[3단계: 1-Click 실행 및 검증 (Act & Verify)]
사장님이 [지금 배포하기] 버튼 딱 1번 누르면 끝!
→ AI가 고품질 이미지/홍보글 자동 생성 
→ 네이버 스마트플레이스, 인스타그램, 당근마켓 자동 동시 게시
→ POS 매출 및 영수증 쿠폰으로 "이번 프로모션으로 번 돈" 직관적 검증
```

## 2. 핵심 디자인 철학 및 원칙 (Core Design Principles)

디자인팀은 작업 시 아래의 **두 가지 핵심 원칙**을 타협 없이 준수해야 합니다.

### ① 일론 머스크의 5단계 엔지니어링 알고리즘 (극단적 단순화)
1. **모든 요구사항에 의문을 제기하라**: "이 그래프가 사장님에게 정말 필요한가? 사장님이 ROAS, CPC, 백분율을 알고 싶어 할까?"
2. **가능한 한 최대한 제거하라**: 복잡한 설정창, 텍스트 벽(Wall of Text), 불필요한 필터, 3단계 이상의 깊은 뎁스 메뉴를 전부 제거합니다.
3. **단순화하고 최적화하라 (토스 스타일 Visual-First)**: 
   - 한 화면에는 **단 하나의 핵심 질문**과 **단 하나의 결정 버튼**만 둡니다.
   - 복잡한 용어 대신 "이번 주 번 돈: +45만 원", "오늘 오신 손님: 18명"처럼 큼직하고 명확한 숫자를 제공합니다.
4. **속도를 높여 주기를 단축하라**: 사장님이 스마트폰을 켜서 조언을 확인하고 실행하기까지 **3초~5초 이내**에 끝나야 합니다.
5. **자동화하라**: 사장님이 디자인 툴을 만지거나 글을 타이핑하지 않도록, AI 생성 미리보기를 제시하고 승인 즉시 자동 배포합니다.

### ② Calm Ergonomic Dark System (2026 APCA 인체공학 테마)
- **Zero Halation & Zero Glare**: 순수 블랙(`#000000`)과 순수 화이트(`#FFFFFF`)를 완전히 배제하여, 어두운 매장 카운터나 야간 마감 시에도 눈이 부시지 않고 피로감이 없습니다.
- **Deep Charcoal Slate Canvas**: 메인 배경은 깊고 편안한 딥 차콜 슬레이트(`rgb(18, 20, 23)` / `#121417`)를 사용합니다.
- **Muted Terracotta Accent**: 눈을 찌르는 형광색 대신 차분하고 따뜻한 테라코타 오렌지(`rgb(217, 107, 39)` / `#D96B27`)를 메인 액션 및 브랜드 포인트로 사용합니다.
- **Soft Sage Green Status**: 매출 상승 및 긍정 지표는 편안한 세이지 그린(`rgb(78, 159, 134)` / `#4E9F86`)으로 표현합니다.
- **Off-white Soft Pearl Text**: 본문과 제목은 눈부심이 없는 부드러운 오프화이트(`rgb(230, 232, 236)` / `#E6E8EC`)와 뮤트 쿨 그레이(`rgb(156, 163, 175)` / `#9CA3AF`)를 적용합니다.

## 4. 디자인 의뢰 범위 및 핵심 화면 목록 (Scope of Work & Screen Inventory)

디자인팀에서 우선 집중하여 고도화해야 할 화면은 총 **8개 핵심 화면**입니다.

### [Group A: 사장님 전용 모바일 화면] (Mobile First - 최우선 순위 P0)

#### 1. [Screen 1] 사장님 데일리 콕핏 (Today's Action Cockpit)
- **목적**: 앱 실행 시 첫 화면. 사장님이 오늘 무엇을 해야 할지 즉시 인지.
- **핵심 요소**:
  - 상단: 오늘 날씨/상권 인프라 뱃지 ("오후 3시 비 예보 🌧️", "성수동 팝업 축제 주간 🎪")
  - 중앙 히어로 카드: **오늘의 1-Click 추천 조언** ("비 오는 날엔 얼큰 국물 파전 세트! 플레이스와 인스타에 지금 홍보할까요?")
  - 하단 요약 카드: **이번 주 번 돈 요약** ("AIM 자동 홍보로 +38만 원 더 벌었어요", 영수증 룩앤필)
  - CTA 버튼: `[추천 내용 확인하기]` (눈에 띄는 Terracotta Button)

#### 2. [Screen 2] 1-Click 캠페인 확인 및 자동 배포 시트 (1-Click Approval Sheet)
- **목적**: AI가 만든 홍보 콘텐츠를 검토하고 단 1번의 탭으로 배포.
- **핵심 요소**:
  - 채널 탭: [네이버 플레이스 소식] / [인스타그램 피드] / [당근마켓 비즈프로필] 실물 프리뷰
  - AI 생성 비주얼: 먹음직스러운 음식/매장 사진 + 매력적인 헤드카피
  - 공정위 심의 통과 배지: `[광고 심의 통과 안전 카피 ✓]`
  - 하단 고정 단일 CTA: `[지금 1초 만에 자동 배포하기]` (단일 Primary Button)

#### 3. [Screen 3] 초간단 가치 검증 영수증 리포트 (Attribution Ledger)
- **목적**: 사장님이 지불한 월 구독료 대비 "얼마를 벌었는지" 명확히 입증.
- **핵심 요소**:
  - "이번 달 투자: 49,000원 ➔ 창출 매출: 4,320,000원 (ROI 88배)"
  - 마케팅 복잡 지표 완전 배제! "쿠폰 들고 오신 손님 42명", "비 오는 날 파전 세트 18건 판매"
  - 모바일 영수증 종이 찢김 효과 또는 직관적 카드 형태 디자인

#### 4. [Screen 4] 15초 숏폼 크리에이터 안심 의뢰 뷰 (Creator Escrow Sheet)
- **목적**: 인플루언서 섭외 방법을 모르는 사장님을 위한 15초 숏폼 연결.
- **핵심 요소**:
  - 복잡한 협상 불필요: 3문항 선택 (홍보할 메뉴, 타겟 고객, 원하는 분위기)
  - AI가 자동 생성한 15초 콘티 (4씬 구성 시각화)
  - 동네 인기 크리에이터 추천 카드 (일치율 98%, 평점 4.9)
  - 안심 에스크로 결제 및 결과물 보증 배지

#### 5. [Screen 5] 1분 초간단 온보딩 로드맵 (Quick 3-Step Onboarding)
- **목적**: 첫 가입 후 이탈 없이 1분 만에 세팅 완료.
- **핵심 요소**:
  - Step 1: 내 매장 네이버/인스타 아이디 연결 (원클릭)
  - Step 2: AI 자율 인프라 감시 모드 작동 개시 (레이더 애니메이션)
  - Step 3: 첫 번째 1-Click 추천 받아보기 완료 축하 화면

### [Group B: 총괄 관리자 데스크톱 웹 콘솔] (Desktop First - P1)

#### 6. [Screen 6] 플랫폼 총괄 관제 & 플릿 FinOps 워룸 (Master Admin Deck)
- **목적**: 전체 가맹 매장의 실시간 운영 및 인프라 신호 수집 상태를 한눈에 관제.
- **핵심 요소**:
  - 4대 전사 KPI 카드 (총 가맹점 수, 활성 매장률, 전사 창출 매출 GMV, 월간 구독 매출 MRR)
  - 가맹점 실시간 플릿 그리드 (매장명, 업종, 현재 적용된 인프라 트리거, 최근 배포 상태)
  - 실시간 인프라 센서 상태 맵 (기상청/기념일/지역 축제 API 수신 상태)

#### 7. [Screen 7] 고위험 카피 인적 검토/격리 큐 (Quarantine Queue)
- **목적**: 의료법, 표시광고법 등 법적 분쟁 위험이 있는 카피를 AI가 1차 격리하고 관리자가 심의.
- **핵심 요소**:
  - 위반 의심 라벨 (`[의료법 제56조 위반 위험]`, `[과장 광고 소지]`)
  - 원문 vs AI 안전 수정안 Side-by-Side Diff 비교 뷰
  - 관리자 승인/반려 원클릭 액션 패널

#### 8. [Screen 8] 서비스 소개 & 실시간 ROI 계산 랜딩 (Landing Page)
- **목적**: 외부 유입 사장님을 위한 설득형 모바일/웹 랜딩.
- **핵심 요소**:
  - "컨설팅 비용 0원, 마케팅 직원 월급 대신 월 4.9만 원"
  - 내 업종과 월 매출을 넣으면 "예상 추가 순이익"을 즉시 계산해 주는 인터랙티브 ROI 슬라이더

## 5. 디자인 시스템 및 기술 제약 조건 (Design Tokens & Constraints)

### 5.1 색상 및 표면 토큰 (Calm Ergonomic Dark System)
프로젝트에 이미 정의된 CSS 디자인 토큰([`docs/design/tokens.css`](tokens.css))을 100% 반영해 주셔야 합니다:

```css
/* Surface Hierarchy */
--surface-canvas: #121417;        /* Deep Charcoal Slate (기본 캔버스) */
--surface-panel: #161A20;         /* 사이드바 & 상단 네비게이션 */
--surface-card: #1C2026;          /* Muted Charcoal Container (기본 카드) */
--surface-card-elevated: #262B33; /* 모달, 플로팅 시트, 호버 카드 */
--surface-border: rgba(255, 255, 255, 0.08); /* 1px 미세 테두리 */

/* Brand & Semantic Accents */
--color-primary: #D96B27;         /* Muted Terracotta Orange (주요 CTA 버튼, 브랜드 로고) */
--color-primary-hover: #C25B1D;   /* 버튼 호버/프레스 */
--color-success: #4E9F86;         /* Soft Sage Green (창출 매출, ROI 순이익, 성공 배지) */
--color-warning: #E5A84B;         /* Muted Amber (현안 트리거 알림, 주의) */
--color-danger: #E05D5D;          /* Soft Muted Coral Red (법률 위반 경고, 차단) */

/* Typography */
--text-primary: #E6E8EC;          /* Off-white Soft Pearl (눈부심 방지 본문 및 헤드라인) */
--text-secondary: #9CA3AF;        /* Muted Cool Grey (보조 텍스트, 설명) */
--text-muted: #6B7280;            /* 캡션, 메타 정보 */
```

### 5.2 타이포그래피 & 숫자 규칙
- **서체**: `Pretendard` (Web & App 기본 본문용)
- **숫자 고정폭**: 매출, 금액, ROI 등 변동 수치에는 반드시 고정폭 숫자(`font-variant-numeric: tabular-nums`)를 적용하여 시각적 흔들림 방지
- **최소 본문 크기**: 모바일 기준 본문 최소 15px, 주요 수치/라벨 20~28px 이상으로 시인성 확보

### 5.3 인터랙션 및 컴포넌트 규격
- **8pt Bento Grid 시스템**: 패딩, 마진, 간격은 8px 배수 체계 준수
- **터치 영역 (Touch Target)**: 모바일 모든 클릭 요소는 **최소 48px × 48px** 이상 확보 (손이 젖거나 기름진 상태에서도 편안한 터치 고려)
- **코너 라운딩**: 카드는 `14px`~`18px`, 버튼은 `10px`~`12px`, 배지/알약은 `9999px` 풀 라운딩
- **외부 채널 실물 렌더링**: 네이버 플레이스 소식 탭, 인스타그램 피드/릴스, 당근마켓 피드의 최신 모바일 레이아웃 목업과 100% 일치할 것
