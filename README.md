## 🏛️ 전사 3대 솔루션 유기적 통합 아키텍처 (The Tripartite Engine)

AIM은 단순 매장 정보 조회가 아닌, **실시간 상황 감지부터 매출 정산까지 닫힌 루프(Closed-Loop)**로 작동하는 3대 솔루션으로 구성되어 있습니다.

### 1. ⚡ 솔루션 1: 서비스 실행 솔루션 (Core Service Engine)
- **6D 하이퍼 컨텍스트 엔진**: 시대(Era), 상황(Situation), 계절(Season), 세대(Generation), 지역(Region), 계기(Milestone)를 실시간 복합 센싱.
- **실시간 기습 타임어택 (Flash Booster)**: 우천 예보, 유휴 좌석 급증 시 3시간 한정 깜짝 프로모션 기안.
- **반경 1km 경쟁 상권 스파이**: 주변 경쟁 매장의 고객 불만 및 약점을 포착하여 반사이익 역공 전략 수립.
- **플레이스 1위 진단 & 리뷰 방어**: 네이버 스마트플레이스 순위 상승 처방전 및 1점 악성 리뷰 3단 품격 대응.

### 2. 💼 솔루션 2: 유료 가입자 사업자 콕핏 (Subscriber Tenant Cockpit)
- **WTP 재무 기여도 엔진**: 월 구독료 대비 창출된 실제 매출 순이익 귀속(+₩4.32M / ROI 88.2배 달성).
- **Shapley Value 채널 기여도**: 네이버(48%), 인스타그램(32%), 카카오 알림톡(20%)의 공정한 가치 배분.
- **AI 기안 원클릭 승인 데스크 (HITL)**: 감지된 트리거에 맞춰 AI가 사전 기안한 마케팅 액션을 사업주가 원클릭으로 검토 및 즉각 송출.
- **스마트폰 실시간 목업**: iPhone 16 Pro 프레임 내부에서 3대 채널별 카피를 즉시 확인.

### 3. 👑 솔루션 3: 플랫폼 총괄 관리 솔루션 (Master Admin Control Plane)
- **전사 5개 테넌트 플릿 관리**: 성수 베이커리, 강남 리엔 피부과, 청담 헤어살롱, 플로우독 SaaS, 대진정밀공업.
- **FinOps & MRR 대시보드**: 플랫폼 총 MRR ₩545,000, 누적 창출 매출 +₩145.3M.
- **컴플라이언스 격리 큐 (Compliance Quarantine Desk)**: 의료법 제56조 및 표시광고법 위반 고위험군 표현을 사전에 100% 격리하고 수동 심의.
- **분산 에이전트 인프라 텔레메트리**: 99.98% 가동률 모니터링.

## 🚀 빠른 시작 (Local Development)

### 1. 가상환경 및 패키지 설치
```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### 2. 개발 서버 구동
```bash
python3 -m uvicorn aim.web_app:app --port 8000 --host 127.0.0.1 --reload
```
브라우저에서 `http://127.0.0.1:8000/` 접속 시 통합 마스터 포털이 즉시 렌더링됩니다.

### 3. 테스트 검증
```bash
python3 -m pytest -q
```
